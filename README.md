# Portfolio

Personal portfolio of José Antonio González Llambia, built with Next.js (App Router), React 19 and Tailwind CSS 4. It is exported as a static site.

## Development

Requires [pnpm](https://pnpm.io) (version pinned in `package.json`).

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm lint
pnpm build    # static export to ./out
```

Featured projects are edited in `src/constants/projects.ts`.
